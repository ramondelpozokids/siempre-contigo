Accesible por diseño

Siempre Contigo está pensado para personas mayores. Esta web refleja los mismos principios: tipografía legible, contraste alto, navegación por teclado y compatibilidad con lectores de pantalla.

1. Nuestro compromiso

Siempre Contigo, S.L. se compromete a hacer accesible su sitio web conforme al Real Decreto 1112/2018 y, como referencia técnica, las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.2 en nivel AA.

2. Estado de conformidad

Este sitio web es parcialmente conforme con WCAG 2.2 nivel AA debido a las excepciones indicadas más abajo. «Parcialmente conforme» significa que algunas partes del contenido no cumplen plenamente el nivel de accesibilidad exigido.

3. Medidas adoptadas

  • Botón «Texto grande» en la barra superior: aumenta el tamaño de letra, el contraste y el área de pulsación de botones.
  • Estructura clara con encabezados, textos alternativos en imágenes y botones con etiquetas comprensibles.
  • Controles con soporte ARIA (preguntas frecuentes, cookies, tema claro/oscuro).
  • Respeto de prefers-reduced-motion: menos animaciones si el sistema lo pide.
  • Modo claro y oscuro con contraste revisado en ambos temas.
  • Enlaces y botones visibles al navegar con teclado (contorno azul).

4. Limitaciones conocidas

  • Algunas demostraciones de chat usan animaciones de escritura que pueden resultar lentas; el contenido completo permanece disponible en el DOM.
  • Enlaces a secciones de producto aún no publicadas pueden tener contenido provisional.

5. Comentarios y contacto

Si encuentras una barrera de accesibilidad en este sitio, escríbenos a accesibilidad@siemprecontigo.app indicando la página y el problema. Responderemos en un plazo máximo de 10 días laborables.
